
# Tickersoft

Tickersoft is a collection of web services and software for old phones, older computers and modern devices. The idea is simple: you should still be able to message people, read the news or access your files without needing a modern browser or a fast connection.

Tickersoft's frontend is entirely server-rendered and requires **no JavaScript whatsoever**. JavaScript may be used internally for backend tasks, but never needs to run on your device. Whether your browser supports JavaScript has no bearing on compatibility. We support WAP, XHTML and Java ME where possible, and test on actual devices.

**[Website](https://tickersoft.de) | [Documentation](https://tickersoft.de/d/index.php) | [Services](https://tickersoft.de/d/services.php?lang=en) | [Tics](https://tics.li)**

## What's here

- **Konto:** One login for Tickersoft services.
- **Tics:** Social networking with posts, profiles, DMs and groups.
- **Werkstatt:** A collection of everyday tools for notes, planning, communication, file management and other useful tasks.
- **Other projects:** [BijnaVet](https://bijnavet.nl), [WAP.RE](https://wap.re) and [WHY2K](https://why2k.de).
- **Clients:** Java ME applications and software for older Windows systems, alongside the browser versions.

Support varies by device and service. Some parts are already usable, while others are still being developed. See the [documentation](https://tickersoft.de/d/index.php) for details.

## Source code

**Tickersoft's source code will be published on Codeberg.** I'm still polishing a few things before making it open source. GitHub is mainly here for visibility and to help people find the project.

## Why?

Old hardware still works. A lot of the web just stopped working on it. Tickersoft aims to change that without the trackers, bloated pages and unnecessary complexity of much of today's internet.

Available in English, German, Dutch and Polish, although translation coverage varies.
