# Tickersoft

Tickersoft is a collection of web services and software for old phones, older computers and modern devices. 
See it like a carrier without phone towers.

The idea is simple: you should still be able to message people, read the news or access your files without needing a modern browser or a fast connection.

Tickersoft's frontend is entirely server-rendered and requires **no JavaScript whatsoever**. JavaScript may be used internally for backend tasks, but never needs to run on your device. Whether your browser supports JavaScript has no bearing on compatibility. We support WAP, XHTML and Java ME where possible, and test on actual devices.

## What's here

### Konto
The heart of your experience in the network, powering it all.
### Tics
Social networking with posts, profiles, DMs and groups.
### Werkstatt: 
A collection of everyday tools for useful tasks, including but not limited to:
- Platte: cloud-storage (soon able to do much more than that)
- ElektroPost: (SMTP/IMAP client, bring your own account)
- Keinplan: Calendar and reminders
- Schatzkammer: An offline password manager that you set up by sending encrypted entries that will be eliminated on request by the next time the application syncs.

### Other projects:**
- [BijnaVet](https://bijnavet.nl) (A video sharing site),
- [WAP.RE](https://wap.re) and [WHY2K](https://why2k.de).
- **Clients:** Java ME applications and software for older Windows systems, alongside the browser versions.

Support varies by device and service. Some parts are already usable, while others are still being developed. See the [documentation](https://tickersoft.de/d/index.php) for details.

## Where the fuck's the code?!
As of right now, you might notice that we haven't made any of the code available for review yet. However, this will change very soon, as we're still polishing a few things before making it open source.  
Apart from some "secret sauce" exclusive to Tickersoft we'd prefer to license/keep to ourselves instead (think the exact logic that makes our services so adaptable), as well as some obvious redactions that would otherwise be a case of **OPSEC LEVEL: Yeah we quit**, when this is settled with, **Tickersoft's source code will be published on Codeberg.** 
GitHub mainly exists as another funnel or source for visibility and to help people find the project through yet another channel.

**As a result, if you only have a Github account, you're allowed and ALL issues/ideas regarding the code over here as well.
The link to the appropriate repo will be provided as soon as the code is open-source.**

## Why even bother?

Because hardware still works, and a lot of the web just stopped working on it. Tickersoft aims to change that without the trackers, bloated pages and unnecessary complexity of much of today's internet.

Available in English, German, Dutch and Polish, although translation coverage varies.
